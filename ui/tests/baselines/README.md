# Visual baselines

These PNGs are the reference images for `tests/visual-baseline.spec.ts`: seven scenes of the DEV demo feed (Live In Game, Agent Select, Lobby with 3 players, Player Details, Match Details, My Stats and My Stats for a new account), each one 1000×800 in Barlow with the default theme and the fixed page clock, compared with `toHaveScreenshot` (at most 0.2% of the pixels may differ). Pixels depend on the exact browser build and its fonts, so they are generated only by the manual `Build` run with `update_baselines=true` (job `baselines-render`, in the pinned `mcr.microsoft.com/playwright` image that CI also compares them in) and committed by that run, never on a developer machine: locally the spec skips itself unless `VISUAL_BASELINES=1`, and a local render would not match CI. To refresh them on purpose after a change that is meant to alter the look, start the `Build` workflow by hand on your branch with `update_baselines` ticked, look at the new PNGs in the commit it makes, and keep them only if the change is the one you intended.
